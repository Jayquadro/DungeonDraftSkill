## Description

Nucleo della libreria ddforge: serializzazione dei tipi Godot, allocazione node_id, caricamento/svuotamento del template, modello dati e primitive di disegno. Criterio di completamento: pytest verde e uno script demo che produce un file con 1 stanza + 1 porta, verificato da Jay aprendolo in Dungeondraft. Riferimento: docs/SPEC.md §5, §6.1-6.5, §12.
